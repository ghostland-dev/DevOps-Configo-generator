# Configo Generator

Generator for DevOps configuration files (Docker, CI pipelines, Kubernetes).

## Features

- Form-driven configuration builder
- Instant preview of generated files
- Copy / download output

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/configo-generator.git
cd configo-generator
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
